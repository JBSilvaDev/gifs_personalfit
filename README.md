# PersonalFit - Animations

Coleção de GIFs animados para auxiliar na orientação e na execução correta de
exercícios físicos.

## Conteúdo

- `src/`: arquivos GIF com demonstrações dos exercícios.
- [exercicios_v3.json](https://gist.githubusercontent.com/JBSilvaDev/0197e3962fcd1253e565cbb61bbf08eb/raw/exercicios_v3.json):
  nomes dos exercícios e referências aos respectivos GIFs.

O arquivo JSON pode ser usado como catálogo para localizar a animação
correspondente a cada exercício.

## Créditos

Os arquivos GIF foram obtidos do projeto
[exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset).
